Реализован адаптивный каталог для практической работы №2 по технологиям разработки программного обеспечения. Страница читает 18 товаров из CSV, использует цвета и размеры из theme.json и три SVG из dataset.

Добавлены семантическая разметка, панель фильтров, поиск, сортировка, информационный блок и подвал. Сетка Grid меняется с трех колонок на две и одну; Flexbox организует шапку, панель сортировки и метаданные. Стили разделены на SCSS partial-файлы с переменными, миксинами, вложенностью и color.mix; скомпилированный CSS включен в проект.

Предусмотрены загрузка, пустая выдача, пустой каталог и ошибка чтения CSV. События фильтров сохраняют сообщение об ошибке загрузки. Данные выводятся через textContent.

Проверено:

- npm run build — успешно.
- npm test — 6 тестов пройдены.
- Браузер: 375, 768 и 1440 px, горизонтального скролла нет.
- Совместная фильтрация, сортировка, сброс и пустая выдача.
- Ошибка загрузки при отсутствии рабочего CSV, включая ввод в поиск после ошибки.

Результаты и ограничения проверки описаны в docs/verification.md, запуск — в README.md.
