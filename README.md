# Практическая работа №2
Адаптивный каталог «Учебная полка»: 18 товаров из предоставленного CSV, поиск, категория, верхняя граница цены, рейтинг и сортировка. Предусмотрены пустая выдача и ошибка загрузки. Данные выводятся через textContent.

## Запуск
Нужен Node.js 20.19+ и npm. Из корня проекта:
```powershell
npm ci
npm run build
npm start
```
Откройте http://localhost:8080. Открытие index.html через file:// не поддерживает загрузку CSV.
Сборка: npm run build. Наблюдение: npm run watch (в отдельном терминале).
Проверка логики: npm test.

## Структура
- dataset — неизмененные исходные материалы; example — предоставленный пример.
- data — рабочая копия CSV и темы; images — копии трех SVG.
- js/catalog.js — преобразование и проверка CSV, фильтрация; js/app.js — загрузка и DOM.
- scss — variables, mixins, base, layout, components и главный styles.scss.
- css/styles.css — результат Sass; scripts/server.js — локальный сервер.

Цвета, радиус 14px и шаг 16px перенесены из theme.json в _variables.scss. При изменении темы обновите переменные и пересоберите CSS. CSV читается при запуске, иллюстрации сопоставляются трем категориям.

## Организация стилей
SCSS-переменная вычисляется при сборке и исчезает из CSS. CSS custom property сохраняется в браузере, участвует в каскаде и может меняться во время работы страницы.
Partial-файлы с префиксом _ разделяют обязанности и подключаются через @use.
Миксин panel применяется к фильтрам, карточкам, информационному блоку и сообщениям; focus — к интерактивным элементам.
Шаг 8: вложенность ограничена компонентом и его элементами. Шаг 9: повторяющееся оформление вынесено в mixin.
Шаг 10: color.mix создает светлый оттенок акцента; отступы и радиусы вычисляются из базовых значений.
Шаг 12: Grid выводит три, две или одну колонку. Шаг 13: при 1100px снижается плотность карточек, при 767px фильтры переходят над каталогом; Flexbox организует шапку, панель сортировки и метаданные.

## Ручная проверка перед сдачей
На ширинах 375, 768 и 1440px проверьте отсутствие горизонтальной прокрутки, читаемость карточек и видимость клавиатурного фокуса.
Проверьте поиск, сочетание фильтров, сортировку и сброс. Цена 0 дает пустую выдачу.
В Network CSV должен отвечать 200. Для ошибки временно переименуйте data/catalog.csv, обновите страницу и затем восстановите файл.
Автоматические тесты проверяют данные, фильтрацию и поврежденный CSV. Результаты проверки браузером на ширинах 375, 768 и 1440px записаны в docs/verification.md.
